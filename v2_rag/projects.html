To design and build an autonomous mini-car capable of real-time maze exploration, obstacle detection, and optimal path planning without human intervention.

My Contributions

  • Processed real-time sensor telemetry data for automatic obstacle avoidance and route optimization.
  • Integrated high-level algorithmic software logic seamlessly with hardware microcontrollers.

Gamified Children's Banking & Reward System
