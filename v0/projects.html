Autonomous Maze-Solving Smart Car System

Coursework

Designed and built an autonomous mini-car capable of real-time maze exploration, obstacle detection, and optimal path planning without human intervention.

🎯 Purpose

To engineer a robotic platform that navigates unpredictable labyrinth environments independently, evaluating sensor telemetry to map and solve mazes efficiently.

💻 My Contributions

Developed core software control modules implementing maze-solving algorithms (such as Wall-Following and Breadth-First Search/BFS), processed real-time sensor telemetry data for automatic obstacle avoidance, and seamlessly integrated software logic with hardware microcontrollers.

Gamified Children's Banking & Reward System

Coursework

Designed a secure and engaging digital banking platform tailored for children, helping them build early financial literacy through simulated savings and interactive rewards.

🎯 Purpose

To create an intuitive, secure fintech interface that introduces young users to financial concepts like saving, budgeting, and goal-setting through gamified positive reinforcement.

💻 My Contributions

Implemented core transaction modules for secure deposits and withdrawals with robust state management, developed a gamified reward system featuring achievement badges and virtual points, and crafted clean, user-friendly workflows for young learners.
